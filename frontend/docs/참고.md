# Frontend 참고 문서

## 1. 프로젝트 목적
이 프로젝트는 React + Vite 기반의 로컬 LLM 채팅 앱입니다.

- 사용자는 React 화면에서 질문을 입력한다.
- 프론트엔드는 FastAPI 백엔드만 호출한다.
- FastAPI가 Ollama 서버와 연동해 응답을 반환한다.
- 채팅 UI는 Apple 스타일의 단순하고 세련된 인터페이스로 구성한다.

---

## 2. 핵심 구현 방향

### 기술 조건
- React + Vite 사용
- JavaScript 사용
- TypeScript 미사용
- CSS는 일반 CSS 사용
- API 호출은 axios 사용
- 상태 관리는 useState만 사용
- API 호출 로직은 src/api/chatApi.js로 분리
- 프롬프트 모드 데이터는 src/api/promptModes.js로 분리
- Ollama를 직접 호출하지 않고 FastAPI만 호출

### 권장 라이브러리
- axios
- react-markdown
- remark-gfm

## 4. 주요 기능 요구사항

### 4-1. 채팅 기능
- 사용자가 입력창에 메시지를 입력한 뒤 Shift+Enter 또는 전송 버튼으로 전송 가능
- 전송 즉시 사용자 메시지를 화면에 표시
- 로딩 인디케이터 표시
- AI 응답 수신 후 메시지 버블로 표시
- 대화 초기화 버튼으로 채팅 내용 초기화 가능

### 4-2. Markdown 렌더링
- 사용자 메시지와 AI 응답 모두 Markdown으로 렌더링
- 지원 문법:
  - 제목
  - 굵게 / 기울임
  - 리스트
  - 코드 블록
  - 인용문
  - 링크
  - 표
  - 체크박스

### 4-3. 복사 기능
- AI 메시지 우측 상단 버튼으로 전체 텍스트 복사
- 코드 블록 헤더 우측 버튼으로 코드 전체 복사
- 복사 성공 시 체크 아이콘 표시

### 4-4. 오류 처리
- 422 오류: FastAPI의 Pydantic validation 에러를 파싱해 표시
- 500 오류: 서버 오류 메시지 표시
- 에러 배너는 채팅 헤더 아래에 표시

## 5. 백엔드 연동 정보

### API 기본 주소
- Vite 환경 변수:
```env
VITE_API_BASE_URL=http://localhost:8000
```

### 요청 예시
POST /chat
```json
{
  "message": "안녕",
  "model": "gemma4:e4b",
  "system_prompt": "너는 친절한 AI야.",
  "temperature": 0.7,
  "top_p": 0.9,
  "num_predict": 256
}
```

### 응답 예시
```json
{
  "model": "gemma4:e4b",
  "message": "안녕하세요!",
  "elapsed_time": 1.23
}
```

## 6. 설정 패널 구성
좌측 설정 패널에는 아래 항목이 표시되어야 한다.

1. 모델 선택
   - /models API로 동적으로 모델 목록 로드
2. 프롬프트 모드 선택
   - 기본 / 강사용 / 코드 / 오류 해결 / 표 형식
3. 시스템 프롬프트 입력
   - 모드 선택 시 자동 반영
4. Temperature 슬라이더
5. Top P 슬라이더
6. Num Predict 입력

## 7. 디자인 가이드
디자인은 Apple 감성의 미니멀하고 세련된 느낌으로 구성한다.

### 색상 포인트
- 배경: 밝은 회색 계열
- 주요 포인트: Apple Blue
- 사용자 버블: 파란색
- AI 버블: 밝은 회색 또는 흰색

### 스타일 포인트
- Frosted Glass 느낌
- 부드러운 그림자
- 둥근 모서리
- 자연스러운 애니메이션

## 8. 구현 시 주의사항
- 프론트엔드는 Ollama를 직접 호출하지 말고 FastAPI만 호출한다.
- API 호출 코드는 반드시 src/api/chatApi.js에 분리한다.
- 프롬프트 모드 데이터는 src/api/promptModes.js에 분리한다.
- 컴포넌트는 역할별로 분리해 가독성을 높인다.
- 초보자도 읽기 쉬운 코드 구조로 작성한다.
- 에러 상황을 미리 처리해 UX를 깨지 않게 만든다.
